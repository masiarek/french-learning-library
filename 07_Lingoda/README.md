# 07_Lingoda — the Lingoda course

**Level:** A1 · for the owner, one course level at a time

The owner's Lingoda course, levels A1.1 to A2.2, one page per level as each is made. A page here is the owner's own HTML file, published as it is.

| Page | What it holds |
|---|---|
| [A1.1 Vocabulaire /vɔkabylɛʁ/](a1_1_vocabulaire.html) | Every word and phrase from the Vocabulaire page of each A1.1 lesson, the Orientation and chapters 1 to 13: French, IPA and English, an example sentence under each entry with the word in bold, each lesson's *Au quotidien* /o kɔtidjɛ̃/ phrase and end-of-lesson idiom; words taught in an earlier lesson are listed under *Review* |

The vocabulary page is HTML, not a Markdown table, so `tools/check_ipa.py` does not check its IPA and no Anki deck is made from it yet.
