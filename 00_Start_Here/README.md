# 00_Start_Here

**Level:** 101 · for anyone

## What this library is

One idea per page, and every claim that a program can check, checked by a program that runs. The pages are short, the programs are stdlib-only Python, and the output printed on any page came from an actual run that CI re-checks on every push. Claims no program can check, which in a language are many, name their source and say how sure they are.

It is about French: first its sounds as the dictionaries write them, later its grammar and vocabulary wherever a page can make a claim and show it. It is a sibling of the [math library ↗](https://masiarek.github.io/math-learning-library/) and the [learning to learn library ↗](https://masiarek.github.io/learning-to-learn-library/), and it points across to them for the sets its programs use and for how to study so that it stays.

## What to read first

[**01_Sounds/**](../01_Sounds/README.md) — *What does the French in the dictionary sound like?* The International Phonetic Alphabet, which every French dictionary and course book uses, read through what an English reader already knows of it: 21 shared symbols, the 15 that are French alone, and the three marks that tell a French line from an English one.

## Po polsku, w skrócie

Biblioteka do nauki francuskiego, zbudowana jak jej siostrzane biblioteki: jedna myśl na stronę, a każde twierdzenie, które da się sprawdzić programem, sprawdza program, którego wynik jest na stronie. Zaczyna się od dźwięków, czyli od alfabetu fonetycznego, którym posługuje się każdy słownik.
