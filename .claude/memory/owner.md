# The owner

How the owner of this library works, as learned from sessions in this repository and its siblings. Update when a session shows something new.

- Writes short, fast messages, often from a phone; typos are normal ("grench" was French). Read for intent, and ask only when two readings lead to different work.
- Does not want to check or click anything: every finished piece of work goes all the way to merged on `master` in the same session (see `CLAUDE.md`). The one thing only they can do is a repository setting, such as turning on Pages; ask for exactly that, with the URL.
- Reads Polish and German, and learned school subjects under Polish names: every new page carries `## Po polsku, w skrócie` and `## Auf Deutsch: Stichwörter`. A Polish comparison (ą, ę, ń, the Polish „u") helps on a sounds page.
- Is learning French with Assimil's *French with Ease*; the audio is on their external drive, unreachable from a cloud session.
- Asks "is it correct" about dictionary conventions (Oxford's IPA) and values a checked answer over one from memory: when a session runs on the iMac through Remote Control it can read the dictionary pages; a cloud session cannot, and says so.
- Keeps three sibling libraries (math, learning to learn, Rust) built the same way; a page here links across rather than repeating them.
