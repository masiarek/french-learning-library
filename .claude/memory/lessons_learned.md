# Lessons learned

Pitfalls met in earlier sessions. Check here before repeating an approach.

- **Dictionary sites are blocked in cloud sessions** (Oxford Learner's, Larousse, Le Robert, Wikipedia) by the environment's network policy. A session on the owner's iMac through `claude remote-control` can read them, with `curl` from the shell when the web-fetch tool is refused. From the cloud, write from memory and say so.
- **Nasal vowels are two code points** (vowel plus combining tilde U+0303). Normalise to NFD before counting or splitting a transcription, and match longest symbol first so that /ɑ̃/, /dʒ/ and /əʊ/ stay whole.
- **Oxford's key has 46 symbols, not 44**: it adds the weak /i/ of *happy* and /u/ of *situation*. A 44-phoneme inventory marks the last vowel of *lazy* as unknown.
- **The site builds from `master`** here, as in the math library; the learning-to-learn library uses `main`. Check before copying a workflow across.
- **Szypowska's notation needs a tokenizer, not a chain of replaces.** Her *ua* is /wa/ and her *w* is /v/, so replacing *ua* first and *w* second turns the *w* that *ua* produced into a *v*. Read the brackets left to right, longest match first (*wua, üi* before *ua, ui, w*), and never re-read what was written. The check used while writing lessons 3 to 5 is kept in this session's history only; `tools/check_ipa.py` checks the inventory, not the book's brackets.
\n- **Anki's CSV importer wants a parent deck's cards before its subdeck's.** When a row names `…::Lesson 3::Challenges` before any row names `…::Lesson 3`, Anki creates the parent silently and then, not finding it by name, makes a fresh deck with a `+` for each later card that names it (`Lesson 3+`, `Lesson 3++`, one card each). `tools/combine_anki.py` sorts the challenge decks after the generated ones for that reason; keep any new subdeck after its parent's rows.\n- **Merge pull requests with a merge commit, never squash.** The working branch is restarted from `origin/master` after each merge, and that push is a fast-forward only when master contains the branch's commits. A squash merge (pull request #13) made master a stranger to the branch, the push was refused as non-fast-forward, and force pushes are denied in `.claude/settings.json`. The way out was to merge `origin/master` into the old branch tip and push that; the branch then equals master and the next pull request shows only new commits.
- **YouTube captions are out of reach even from the iMac.** A bridge session's curl gets the watch page, and from it the title, the description and the list of caption tracks; the caption URL itself answers with an empty body without the player's token, and the session's classifier refused the follow-up probe, a denial that covers the outcome. A web search on the video id finds nothing; a search on the exact title finds the Short's URL and nothing else; Invidious, Piped, jina and noembed are blocked. A Short's words come from a screenshot the owner sends.
